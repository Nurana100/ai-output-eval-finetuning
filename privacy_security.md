# Nimbus Notes — Privacy & Security

- All notes are encrypted at rest using AES-256 and in transit using TLS 1.3.
- Nimbus Notes is GDPR compliant. EU user data is stored in EU-based data centers.
- Optional end-to-end encryption ("Locked Notes") is available on Pro and Team plans; when enabled, Nimbus Notes staff cannot read the contents of locked notes, and a lost password on a locked note cannot be recovered by support.
- Account data is retained for 90 days after account deletion is requested, after which it is permanently purged. During this window, deletion can be reversed by contacting support.
- Nimbus Notes does not sell user data to third parties. Aggregated, anonymized usage analytics may be used to improve the product.
- Two-factor authentication (2FA) is available on all plans via authenticator app or SMS.
